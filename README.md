# PRSPCT Landing

Framer-style marketing landing page for **PRSPCT** — an AI prospecting & sales CRM.

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## What’s included

- Brand-first hero with rotating AI keyword animation
- Full-bleed product canvas (prospects + pipeline mock)
- Feature / pipeline / workflow sections
- Stats, pricing (monthly/annual toggle), FAQ accordion
- Final CTA band + footer
- Responsive layout for desktop and mobile
